# ميسر — تطبيق الأدوات الذكية (أندرويد)

تطبيق أندرويد أصلي مستقل تماما (Kotlin وJetpack Compose)، بمعرف `com.muyassir.app`، يجمع 74 أداة يومية وتعليمية وحسابية تعمل على الجهاز.

- **الأقسام:** تحويل الملفات، الصور والتصميم، الطالب والمعلم، الخدمات السعودية، الإنتاجية، إنشاء المستندات، الحسابات والمحولات، الأدوات الذكية.
- **الخصوصية:** المعالجة محلية، لا حسابات ولا إعلانات ولا تتبع. الإنترنت يستخدم فقط لتحديث أسعار العملات عند طلب المستخدم. الملفات المؤقتة تحذف عند الإنهاء ونواتج المعالجة بعد 24 ساعة.
- **المكتبات (كلها مرخصة للاستخدام التجاري):** PDFBox-Android (Apache 2.0)، ZXing (Apache 2.0)، Tesseract4Android وبيانات tessdata_fast (Apache 2.0)، ML Kit من Google (شروط Google المجانية)، خط IBM Plex Sans Arabic (OFL 1.1).

## البناء
GitHub Actions مع كل دفع: اختبارات الوحدات، Lint، بناء AAB وAPK، ثم محاكي يشغل اختبارات المحركات الحقيقية (PDF وOffice وOCR العربي والصور وZIP والهجري) ويفتح كل شاشة أداة ويصورها إلى فرع `ci-shots`، وتشغيل النسخة المصغرة على أندرويد 8 و11 و15.
